git push推送失败

​ 将博客上线git时遇到的第一个问题是git push卡在Writing objects:58%.查询CSDN博客得知故障原因为HTTP缓存不足。

​ 解决方案：在博客根目录执行如下命令，将上传缓存调到500MB.

​ 重新push，故障消失。

404

​ 推送成功，十分钟后访问Nightour7.github.io仍然404报错。

​ 解决方案：

​ 1.修改_config.yml中的url大小写，十分钟后故障仍存在。

​ 2.检查仓库公开性，发现非公开……

​ 访问Nightour7.github.io → Settings → General→Danger Zone→Change repository visibility，改为Public；

​ Pages→Build and deployment→Branch改为main。

​ 保存后回到Pages，站点部署成功，访问Nightour7.github.io正常。
